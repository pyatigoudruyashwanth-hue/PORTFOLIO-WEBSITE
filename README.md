# P YASHWANTH Portfolio

## Run locally

```bash
npm install
npm run dev
```

Edit personal details, skills, projects, education, certifications, and achievements in `src/data/portfolio.js`. The resume is served from `public/resume/P_Yashwanth_Resume.pdf`.

Build with `npm run build`. The GitHub Actions workflow deploys `dist` to GitHub Pages when changes are pushed to `main`. In the repository settings, set **Pages → Build and deployment → Source** to **GitHub Actions**.

Before publishing, replace bracketed placeholders, verify all links and claims, test mobile navigation and keyboard focus, and add a favicon/social preview image.
