# Kenchareddy Harsha Portfolio

## Run locally

```bash
npm install
npm run dev
```

Edit personal details, skills, projects, education, certifications, and achievements in `src/data/portfolio.js`. Add the final resume as `public/resume.pdf`; the existing buttons already point to `/resume.pdf`.

Build with `npm run build`. Vercel works with the default Vite settings; for GitHub Pages publish the generated `dist` folder through a Pages workflow.

Before publishing, replace bracketed placeholders, verify all links and claims, test mobile navigation and keyboard focus, and add a favicon/social preview image.
